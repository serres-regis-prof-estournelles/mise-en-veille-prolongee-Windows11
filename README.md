# Remettre la mise en veille prolongée sous Windows 11

1️⃣ Pour de "vieux" utilisateurs de Windows, la disparition de la "Mise en veille prolongée" peut être déstabilisante. Les habitudes sont parfois tenaces. Pourtant, on peut la réactiver facilement.
2️⃣ Téléchrager er ouvrir le fichier Activer_Veille_Prolongee.bat
3️⃣ Faites un clic droit dessus → Exécuter en tant qu'administrateur
4️⃣ Une fois exécuté, l'option "Mise en veille prolongée" apparaîtra dans le menu Démarrer → Marche/Arrêt
5️⃣ Après cela, quand vous cliquerez sur le bouton d'alimentation dans le menu Démarrer, vous verrez les options : Veille, Arrêter, Redémarrer, et Mise en veille prolongée.
6️⃣ Si l'option n'apparaît toujours pas, essayez de vous déconnecter puis reconnecter, ou redémarrez l'ordinateur.
